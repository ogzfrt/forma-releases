# Forma Conversion Studio — Windows

PNG/SVG dönüştürme, vektör düzenleme, görsel araçları, PDF ve toplu işlem için Windows masaüstü uygulaması.

## İndirme

[Son Windows kurulum sürümünü aç](https://github.com/ogzfrt/forma-releases/releases/latest). Assets bölümündeki **Forma-Setup-VERSION.exe** dosyasını indirip çalıştır. Windows 10/11, x64 içindir. Uygulamanın çalışması için Node.js veya GitHub hesabı gerekmez.

Eski 0.2 ZIP sürümünden geliyorsan bu kurulum dosyasına bir kez geçmen gerekir. Sonraki yayımlanmış sürümleri uygulama kendisi denetleyip arka planda indirebilir; normal kapanışta kurabilir. Ayarlar ekranından otomatik denetim, arka planda indirme ve kapanışta kurma seçeneklerini değiştirebilirsin. Kaydedilmemiş çalışma varken zorunlu yeniden başlatma yapılmaz.

Dosyaların ve projelerin bilgisayarında işlenir; güncelleme için sunucuya yüklenmez. Bu depo yalnızca kurulum ve güncelleme dosyalarını dağıtır; kaynak kod ayrı özel depoda tutulur.

## Doğrulama ve sürüm durumu

0.3.0 → 0.3.1 geçişi iki geçici Windows ortamında gerçek kurulumla denendi: güncelle ve yeniden başlat ile normal kapanışta kurulum yolları geçti. Ayarlar ve örnek proje korundu; aktif/kaydedilmemiş çalışma korumaları doğrulandı.

Bu erken geliştirme sürümüdür; arayüz ve özellikler geliştirilmeye devam ediyor. macOS sürümü henüz yok. Windows yayıncı sertifikası henüz bulunmadığından kurulumda bilinmeyen yayıncı uyarısı görülebilir. Uygulama içindeki güncellemeler ayrıca imzalı sürüm bildirimi ve dosya bütünlüğü kontrolü kullanır.
