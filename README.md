# Forma Conversion Studio — Windows

PNG/SVG donusturme, vektor duzenleme, gorsel araclari, PDF ve toplu islem icin Windows masaustu uygulamasi.

## Indirme

[Son Windows kurulum surumunu ac](https://github.com/ogzfrt/forma-releases/releases/latest). Assets bolumundeki **Forma-Setup-VERSION.exe** dosyasini indirip calistir. Windows 10/11, x64 icindir. Uygulamanin calismasi icin Node.js veya GitHub hesabi gerekmez.

Eski 0.2 ZIP surumunden geliyorsan bu kurulum dosyasina bir kez gecmen gerekir. Sonraki yayimlanmis surumleri uygulama kendisi denetleyip arka planda indirebilir; normal kapanista kurabilir. Ayarlar ekranindan otomatik denetim, arka planda indirme ve kapanista kurma seceneklerini degistirebilirsin. Kaydedilmemis calisma varken zorunlu yeniden baslatma yapilmaz.

Dosyalarin ve projelerin bilgisayarinda islenir; guncelleme icin sunucuya yuklenmez. Bu depo yalnizca kurulum ve guncelleme dosyalarini dagitir; kaynak kod ayri ozel depoda tutulur.

## Surum durumu

Bu erken gelistirme surumudur; arayuz ve ozellikler gelistirilmeye devam ediyor. macOS surumu henuz yok. Windows yayinci sertifikasi henuz bulunmadigindan kurulumda bilinmeyen yayinci uyarisi gorulebilir. Uygulama icindeki guncellemeler ayrica imzali surum bildirimi ve dosya butunlugu kontrolu kullanir.
